# YuvaIntern – Week 1: Python for Machine Learning & Data Preprocessing

## Project Overview
This project is part of the AI Pioneers Machine Learning Internship offered by YuvaIntern.

The objective is to understand Python fundamentals, explore a dataset, perform data cleaning, handle categorical variables, apply normalization, and conduct Exploratory Data Analysis (EDA).

## Dataset Description
The Student Performance dataset contains 395 student records and 33 attributes.

It includes:
- Student age and gender
- Family background
- Study time and attendance
- Previous grades
- Final academic grades

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Tasks Performed

1. Imported the required Python libraries.
2. Loaded and explored the Student Performance dataset.
3. Inspected dataset structure and statistical summaries.
4. Checked missing values and duplicate records.
5. Handled missing values where required.
6. Removed duplicate records where present.
7. Converted categorical variables using One-Hot Encoding.
8. Applied Min-Max normalization.
9. Performed Exploratory Data Analysis.
10. Created visualizations:
    - Distribution of Final Grades
    - Study Time vs Final Grades
    - Gender Distribution
11. Exported the processed dataset into CSV format.

## Project Files

- `YuvaIntern_Week1_Data_Preprocessing.ipynb` – Python implementation.
- `cleaned_student_performance.csv` – Processed dataset.

## How to Run

1. Download the project notebook.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the `.ipynb` notebook.
4. Run the cells sequentially.
